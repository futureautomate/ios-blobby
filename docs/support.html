Common questions

Where is my data? Only on your iPhone. Blobby has no account and no cloud sync.

How do I move to a new phone? Settings → Export backup, save the file to Files or iCloud Drive, then on the new phone Settings → Import backup.

Reminders don't appear. Check iPhone Settings → Notifications → Blobby is allowed, and that a reminder time is set on the habit.

How do I take a day off? Set which days a habit repeats, or long-press a habit → Pause. Rest days and paused days never break your streak.

How do I delete everything? Settings → Reset all data.
